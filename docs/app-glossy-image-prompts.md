# Icônes glossy de l'app (2026-11-06)

**Les icônes ne changent pas.** Ce sont les mêmes icônes que dans l'app aujourd'hui, avec juste un effet glossy, comme les objets 3D de l'inscription.

**Comment faire :** une seule conversation ChatGPT pour toutes les icônes. Envoie d'abord le **style** (une seule fois), puis une ligne par icône. Enregistre chaque image sous le nom indiqué, puis envoie-les-moi.

Si ChatGPT dessine un damier gris et blanc autour, réponds : « *real transparent background, no checkerboard* ».

---

## 1. Le style (à envoyer une fois, au début)

```
For every icon I describe next: make a glossy 3D version of that exact icon, nothing added, nothing removed. Soft jelly-like material in mauve (#C5A8BB) with darker mauve depth (#8A6380), a soft white highlight on the top left, rounded smooth edges, a very soft pink glow (#E8AACD). Simple and clean like a premium iOS app icon, not shiny like chrome, no sparkles. Centered, the icon fills 80% of a square image. Real transparent background (PNG with alpha, no checkerboard, no white). No text, no letters, no circle or bubble behind the icon.
```
