## 4. "What data do you collect?" forms

These answers come from the privacy policy of 9 November 2026. Lita's lawyer should check them.

### Apple (App Privacy)

| Data | Collected | Linked to her | Used for tracking |
|---|---|---|---|
| Email address | Yes (account) | Yes | No |
| Name (first name) | Yes, optional | Yes | No |
| Health (skin conditions, allergies, pregnancy, treatments, journal) | Yes, only with her consent | Yes | No |
| Photos (Dekod selfie) | Yes, sent once and then deleted | Yes | No |
| Approximate location | Yes (only for the climate readings when travelling) | Yes | No |
| Purchases (her spending in the budget) | Yes | Yes | No |
| Other user content (journal notes, messages to Koda) | Yes | Yes | No |
| Product interaction, usage data | Yes (can be turned off) | Yes | No |
| Crash data / diagnostics | Yes (error reports) | Yes | No |

**"Used to track you" (advertising): No for all of it.**

Apple Health data and Face ID never leave the phone, so they are not declared as collected.

### Google (Data safety)

- Data shared with third parties: no. The providers (Supabase, Anthropic, Resend) work on our behalf, and Google doesn't count that as sharing.
- Data encrypted in transit: yes.
- Users can ask for their data to be deleted: yes, in the app.
- Data collected: the same as Apple's table above.
