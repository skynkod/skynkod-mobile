# Skynkod - Skincare Tracking App

Une app mobile pour tracker ta peau avec un AI coach!

## Features

- 📔 Journal quotidien
- 🤖 AI Coach (Koda)
- 📊 Progress charts
- 🔄 Routines
- 📸 Photos
- 💰 Budget tracker
- 🎯 Notifications
- 🆘 Emergency mode

## Tech Stack

- React Native + Expo
- Supabase (database)
- Anthropic API (Claude)
- GitHub

## Setup

1. npm install
2. Create .env.local with your API keys
3. npx expo start
4. Scan QR code with Expo Go
